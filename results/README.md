# Simulation results

Top-level gait-test JSON, images and replay files predate the short-flat/round-outer foot revision. They do not validate the current foot shape.

`rl_flat*` contains the first RL experiments on the current geometry. `curriculum_*` contains the subsequent straight-line and gentle-ramp experiments. Their own summaries specify conditions, seeds and outcomes. See `RL_REPORT.md` and `CURRICULUM_REPORT.md` for measured results.
